Given a set of realizing strings, the praxiological set (`Prax`) consists of
those realizers that are not effort-dominated by a different realizer.

**Theorem** (`Prax.subset`). Every praxiological string is a realizer. *Proof.*
By definition of the subset.

The praxiological minimum (`Prax.Min`) further restricts to those of minimal
duration among the praxiological strings.

**Theorem** (`Prax.Min_subset`). Every praxiological minimum is praxiological.
*Proof.* Again by definition of the subset.

**Theorem** (`Prax.empty`). The empty realizing set has empty praxiological set.
*Proof.* No string can belong to the empty set of realizers.
