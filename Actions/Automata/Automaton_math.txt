**Nowakowska, Theory of Actions (1982), pp. 169–171**

Define an *action automaton* as a system
$$
\langle U,B,\Theta,D,\#,\tau,\pi\rangle,
$$
where $U$ is a set of *states*, $B$ a set of *stimuli* with *null stimulus* $\Theta$, and $D$ an alphabet with pause $\#$. For each state and stimulus, $\tau(u,b)\subseteq D$ is a nonempty set of *admissible actions*, and $\pi:U\times B\times D\to U$ is the *transition map*. A string $d_1\ldots d_n$ is admissible from $(u_0,b_0)$ when each $d_{j+1}$ lies in $\tau(u_j,b_j)$ and $u_j=\pi(u_{j-1},b_{j-1},d_j)$.
